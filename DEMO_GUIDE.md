# Investor demonstration — fresh computation

Open https://demo.tryvivacity.com/. Keep the API host/tunnel running; this release does not have independent durable backend hosting. The world loads ready and waits for **Start experiments**. Reloading stops an existing active session; switching labs and applying settings never start experiments. Allow computation time after starting: a real branch search/validation precedes visible selected execution. Software graphics on the simulation machine can substantially increase wall time.

1. **Object Pickup:** watch actual generated/screened/validated counts in the single inspector. The arm then closes on a free cube, lifts and carries it, opens and leaves it supported at the placement point. Live poses come from fresh MuJoCo execution. Three cards reflect independent validated commands; download their real JSON evidence. Selecting a card does not replace live physics with playback.
2. **Change conditions:** enable/reposition the obstacle or use Blocked scene. Apply settings stops work, rebuilds real geometry and invalidates previous results. Then choose Start experiments. A blocked scene may have no feasible candidate, which is a valid result. Clear route applies new geometry; Start experiments computes new alternatives. Use Stop experiments to cancel backend work.
3. **Discovery:** both declared hypotheses fit newly generated noisy orbital observations. Inspect actual fitted parameters, local uncertainty, residuals, held-out predictions and complexity penalty. The next control cycle can retain the central-only model; no hidden truth is supplied to the fitter. The view shows computed planar trajectories, not a canned orbital animation.
4. **Cloth Folding:** the actuated Panda carries a pre-attached folding bar through an actual 7×7 flex sheet, releases and settles it. Inspect measured alignment and coverage. Explain that it is an experimental constrained fixture, not autonomous garment grasping or arbitrary clothes folding.
5. **Import World:** inspect `fixtures/imports/triangle.glb` or a supported bounded bundle. The view decodes actual geometry. Robot descriptions are staged data; they are not executed through native plugins or represented as physics-ready.

The deterministic policy is not LLM reasoning. Generated proposals are not full physics episodes. Physical success requires actual evaluated execution; zero successes remain zero. Current evidence and limits are in `DEMO_STATUS.md` and the validation reports.

Automated reproducible demonstration: with current UI/API running, set `UI_URL`, `API_URL`, `PROOF_PREFIX`, `CHECK_CONDITIONS=1` and run `node scripts/check-master-live.mjs`. It creates genuine new experiments and captures HTTP/WSS, transforms, metrics, downloads, failure/recovery, layouts and screenshots. This is a verification script, not prerecorded investor output.
